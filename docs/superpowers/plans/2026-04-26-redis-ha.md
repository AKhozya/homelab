# Redis HA Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace single-pod Redis StatefulSet with operator-managed HA Redis (1 master + 1 replica + 3 Sentinels) using OT-CONTAINER-KIT redis-operator. Reconfigure Immich and Paperless-ngx to new endpoints. Decommission old Redis. Add `blocky` ACL user as final commit.

**Architecture:** Flux HelmRelease deploys OT operator. RedisReplication and RedisSentinel CRs in `databases` ns. Apps cut over: Immich uses Sentinel (REDIS_URL=ioredis://base64-json), Paperless uses static master Service (Paperless does not support Sentinel). No soak — single ~30-60 min window.

**Tech Stack:** K3s, Flux v2, SOPS+age, Kustomize, OT-CONTAINER-KIT redis-operator v0.24.0, Redis v7.4.8.

**Spec:** `docs/superpowers/specs/2026-04-26-redis-ha-design.md`

---

## Prerequisites

- Cluster reachable, `fr` zsh function works.
- SOPS configured with age key.
- `databases` ns ResourceQuota has headroom — current usage 2090m/4992Mi req, 15200m/14720Mi lim; hard limits 5/8Gi req, 17/18Gi lim. Adding ~150m/416Mi req, ~1.7c/1.34Gi lim. **Limits are tight — Task 5 verifies + bumps if needed.**
- Existing Redis still serving Immich (76 conns) and Paperless (8 conns). Authentik does NOT use Redis (verified).

```bash
BLOCKY_PASS=$(openssl rand -base64 32 | tr -d '\n=/+' | head -c 40)
```

Decrypt the secret, add `blocky-password` key, re-encrypt:

Then re-encrypt in place by overwriting:
```bash
cp /tmp/redis-passwords-decrypted.yaml "$REDIS_PASSWORDS_FILE"
sops -e -i "$REDIS_PASSWORDS_FILE"
shred -u /tmp/redis-passwords-decrypted.yaml
```

Verify:

### Task 11: Create NetworkPolicy for HA pods

**Files:**
- Create: `infrastructure/controllers/base/databases/redis-ha/networkpolicy.yaml`

- [ ] **Step 1: Create networkpolicy.yaml**

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: redis-ha-network-policy
  namespace: databases
spec:
  podSelector:
    matchExpressions:
      - key: app
        operator: In
        values:
          - redis-replication
          - redis-sentinel
  policyTypes:
    - Ingress
    - Egress
  ingress:
    # 6379 from clients
    - from:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: paperless-ngx
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: immich
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: blocky
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: uptime-kuma
        - podSelector: {}
      ports:
        - { protocol: TCP, port: 6379 }
    # 26379 from Sentinel-aware clients
    - from:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: immich
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: blocky
        - podSelector: {}
      ports:
        - { protocol: TCP, port: 26379 }
    # Replication traffic between redis pods (intra-pod-selector)
    - from:
        - podSelector:
            matchExpressions:
              - key: app
                operator: In
                values:
                  - redis-replication
                  - redis-sentinel
      ports:
        - { protocol: TCP, port: 6379 }
        - { protocol: TCP, port: 26379 }
    # Prometheus scrape redis-exporter
    - from:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: monitoring
      ports:
        - { protocol: TCP, port: 9121 }
  egress:
    # CoreDNS for cluster.local lookups
    - to:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: kube-system
          podSelector:
            matchLabels:
              k8s-app: kube-dns
      ports:
        - { protocol: UDP, port: 53 }
        - { protocol: TCP, port: 53 }
    # Replication / Sentinel inter-pod traffic
    - to:
        - podSelector:
            matchExpressions:
              - key: app
                operator: In
                values:
                  - redis-replication
                  - redis-sentinel
      ports:
        - { protocol: TCP, port: 6379 }
        - { protocol: TCP, port: 26379 }
```

```yaml
        - alert: RedisHASentinelQuorumLost
          expr: count(redis_up{namespace="databases", job=~".*sentinel.*"} == 1) < 2

          annotations:

            severity: warning

        - alert: RedisHAClientReconnectStorm
```
