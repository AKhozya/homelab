# SearXNG Implementation Plan

> **Status:** DONE — live in `apps/base/searxng/` and `apps/staging/searxng/`.

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deploy SearXNG as privacy metasearch engine. Internal (no-auth) + external (Authentik SSO) access, JSON API for automations.

**Architecture:** Raw manifest deploy, homehub/stirling-pdf pattern. Single stateless container, ConfigMap for settings, SOPS secret for instance key, init container copies config to writable emptyDir. Dual-access via Traefik (internal) + Cloudflare Tunnel + Authentik (external).

**Tech Stack:** SearXNG (Docker), Flux GitOps, Traefik Ingress, cert-manager TLS, Kustomize overlays, SOPS/age secrets, Cloudflare Tunnel, Authentik OIDC.

**Spec:** `docs/superpowers/specs/2026-03-16-searxng-design.md`

### Task 3: Deployment

**Files:**
- Create: `apps/base/searxng/deployment.yaml`

- [ ] **Step 1: Create deployment.yaml**

Init container copies `settings.yml` from ConfigMap → writable `/etc/searxng` emptyDir.
Main container runs SearXNG with readOnlyRootFilesystem.

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: searxng
  namespace: searxng
spec:
  replicas: 1
  revisionHistoryLimit: 2
  selector:
    matchLabels:
      app: searxng
  template:
    metadata:
      labels:
        app: searxng
    spec:
      serviceAccountName: searxng
      automountServiceAccountToken: false
      securityContext:
        fsGroup: 977
        runAsUser: 977
        runAsGroup: 977
        runAsNonRoot: true
        seccompProfile:
          type: RuntimeDefault
      initContainers:
        - name: setup-config
          image: busybox:1.37.0
          command:
            - sh
            - -c
            - |
              cp /tmp/config/settings.yml /etc/searxng/settings.yml
              echo "Config copied to /etc/searxng/"
          volumeMounts:
            - name: config-template
              mountPath: /tmp/config
            - name: searxng-config
              mountPath: /etc/searxng
          securityContext:
            allowPrivilegeEscalation: false
            runAsNonRoot: true
            capabilities:
              drop: ["ALL"]
          resources:
            requests:
              cpu: "10m"
              memory: "16Mi"
            limits:
              cpu: "100m"
              memory: "64Mi"
      containers:
        - name: searxng
          image: docker.io/searxng/searxng:2026.3.13-3c1f68c59
          ports:
            - containerPort: 8080
          env:
            - name: SEARXNG_SECRET
              valueFrom:
                secretKeyRef:
                  name: searxng-secret
                  key: SEARXNG_SECRET
            - name: SEARXNG_BASE_URL
              value: "https://search.h0melab.work"
          securityContext:
            allowPrivilegeEscalation: false
            readOnlyRootFilesystem: true
            runAsNonRoot: true
            capabilities:
              drop: ["ALL"]
          livenessProbe:
            httpGet:
              path: /healthz
              port: 8080
            initialDelaySeconds: 5
            periodSeconds: 10
            timeoutSeconds: 3
            failureThreshold: 3
          readinessProbe:
            httpGet:
              path: /healthz
              port: 8080
            initialDelaySeconds: 5
            periodSeconds: 10
            timeoutSeconds: 3
            failureThreshold: 3
          resources:
            requests:
              cpu: "50m"
              memory: "128Mi"
            limits:
              cpu: "500m"
              memory: "512Mi"
          volumeMounts:
            - name: searxng-config
              mountPath: /etc/searxng
            - name: tmp
              mountPath: /tmp
      volumes:
        - name: config-template
          configMap:
            name: searxng-config
        - name: searxng-config
          emptyDir: {}
        - name: tmp
          emptyDir: {}
```

### Task 5: NetworkPolicy

**Files:**
- Create: `apps/base/searxng/networkpolicy.yaml`

- [ ] **Step 1: Create networkpolicy.yaml**

Dual-access (traefik + cloudflare-tunnel), monitoring (uptime-kuma), API consumers (n8n, home-assistant). Egress → DNS + external search engines (HTTP/HTTPS).

```yaml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: searxng-network-policy
  namespace: searxng
spec:
  podSelector:
    matchLabels:
      app: searxng
  policyTypes:
    - Ingress
    - Egress
  ingress:
    # Allow ingress from traefik namespace for internal access
    - from:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: traefik
      ports:
        - protocol: TCP
          port: 8080
    # Allow ingress from cloudflare-tunnel namespace for external access
    - from:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: cloudflare-tunnel
      ports:
        - protocol: TCP
          port: 8080
    # Allow ingress from uptime-kuma namespace for monitoring
    - from:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: uptime-kuma
      ports:
        - protocol: TCP
          port: 8080
    # Allow ingress from n8n namespace for API access
    - from:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: n8n
      ports:
        - protocol: TCP
          port: 8080
    # Allow ingress from home-assistant namespace for API access
    - from:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: home-assistant
      ports:
        - protocol: TCP
          port: 8080
  egress:
    # Allow DNS resolution
    - to:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: kube-system
      ports:
        - protocol: UDP
          port: 53
    # Allow HTTPS to external search engines
    - ports:
        - protocol: TCP
          port: 443
    # Allow HTTP to external search engines (some APIs use plain HTTP)
    - ports:
        - protocol: TCP
          port: 80
```
